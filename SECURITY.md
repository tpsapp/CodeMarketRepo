# Security Policy

## Reporting a Vulnerability or Issue

If you discover a security concern or critical issue in this repository, please report it responsibly via either:

- **GitHub Private Vulnerability Reporting:** Use the *Security* tab on `tpsapp/CodeMarketRepo` to open a private advisory.
- **Email:** `tom.sapp@sappsworld.com` or `tpsapp@hotmail.com`

Please include a clear description of the issue and steps to reproduce it.
